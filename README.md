# Mini Sintetizador

Este proyecto contiene un ejemplo sencillo de un sintetizador digital utilizando la API Web Audio de los navegadores.

## Cómo probarlo

1. Inicia un servidor local en esta carpeta:
   ```bash
   python3 -m http.server
   ```
2. Abre tu navegador y visita `http://localhost:8000/synth.html`.
3. Ajusta los controles de forma de onda, frecuencia y volumen para experimentar con diferentes sonidos.
